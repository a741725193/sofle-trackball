# sofle_trackball

ZMK 4.1 + DYA Studio firmware, generated by `/zmk-keyboard-generator`.

## Build

The repo is consumed by `cormoran/zmk/.github/workflows/build-user-config.yml@main+dya`. Push to a GitHub repo with Actions enabled, and the `Build ZMK firmware` workflow produces all UF2 artifacts.

To download: open the workflow run, scroll to **Artifacts**, download `firmware.zip`.

To flash: drop the appropriate `.uf2` onto each half's USB mass-storage bootloader.

## Customizing

Edit `config/sofle_trackball.keymap` for keymap changes; rebuild is automatic on push.

Edit `boards/shields/sofle_trackball/sofle_trackball_right.conf` (or `_central_dongle.conf`) for Kconfig; same.

For matrix or layout changes, edit `boards/shields/sofle_trackball/sofle_trackball_physical_layout.dtsi` and the `transform` block in `boards/shields/sofle_trackball/sofle_trackball.dtsi`.

For new peripherals, edit `boards/shields/sofle_trackball/sofle_trackball.dtsi` and add a new `<kind>.dtsi` next to it; include it from the appropriate side overlay.
